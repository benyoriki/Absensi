    Keterbatasan LocalStorage

    Aplikasi ini masih memakai LocalStorage sebagai penyimpanan sementara (tahap prototipe). Artinya: data hanya tersimpan di peramban/perangkat masing-masing, TIDAK ada sinkronisasi otomatis antar-HP secara real-time, dan data bisa hilang jika cache/penyimpanan peramban dibersihkan. Untuk produksi, sistem ini perlu dipindahkan ke backend sungguhan (mis. Firebase Authentication + Firestore).
